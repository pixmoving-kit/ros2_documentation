# 最新开发版本（源码安装）

如果计划直接参与 ROS 2 最新版本的开发，可以从源码构建 ROS 2，或安装测试用的二进制版本。这些方式可以让你获得最新的缺陷修复和功能。

<span id="testing-binaries"></span>

## 测试用二进制版本

参阅[测试](../Testing.md)。

<span id="building-from-source"></span>

## 从源码构建

!!! note "说明"

    最新开发版本没有经过与正式发行版同样严格的测试。如果需要稳定版本的 ROS 2，不建议使用它，而应选择已经正式发布的 [ROS 发行版](../../Installation.md)。

通过以下链接，查看对应平台的最新设置说明：

- [Ubuntu Linux](Ubuntu-Development-Setup.md)
- [macOS](macOS-Development-Setup.md)
- [Windows](Windows-Development-Setup.md)

关于如何保持源码为最新状态，参阅[维护源码工作副本](../Maintaining-a-Source-Checkout.md)。

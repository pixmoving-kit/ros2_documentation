# 软件包文档

ROS 软件包文档,即您通过 apt 或其他某种工具安装的特定软件包的文档,可以在多个地方找到。这里是搜索特定 ROS 软件包文档的简要列表 。

- 大多数ROS 2 软件包都有其软件包级别文档 [包含在本索引页中](https://docs.ros.org/en/rolling/p/).

- 所有ROS 2软件包的文件都与其关于 [ROS 指数](https://index.ros.org/). 在ROS索引上搜索软件包将产生其信息,如发布分发, `README.md` 文件、 URL 和其它重要的元数据。

<span id="larger-packages"></span>

## 更大的软件包

MoveIt, Nav2, 微ROS 等更大的软件包在 ros.org 上被赋予自己的域名或子域名。 以下是一个简短的列表 。

- [移动它](https://moveit.ai/)

- [导航2](https://nav2.org/)

- [控件](https://control.ros.org/master/index.html)

- [微型ROS(嵌入式系统)](https://micro.ros.org/)

## 正在将您的软件包添加到 docs.ros.org

所有已发布的ROS 2 软件包都自动添加到docs.ros.org和 [ROS 指数](https://index.ros.org/)。如果您想要启用或配置自己的软件包,请参见: [编写 ROS 2 软件包文档](How-To-Guides/Documenting-a-ROS-2-Package.md).

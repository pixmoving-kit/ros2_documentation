使用下面的表单为您的组织或项目生成 YAML 项。一旦生成,您可以复制 YAML 片断并向您提交拉动请求 。 [adopters.yaml](https://github.com/ros2/ros2_documentation/blob/rolling/source/The-ROS2-Project/Adopters/adopters.yaml) 文件中的 `rolling` 树枝。

<span id="policy"></span>

## 政策

此列表为 **自我报告和自我测试**除非收到投诉,否则只接受最低限度的审查,由于捐款是通过Pull Request提供的,因此易于审计,必要时可以稍后清理。

<span id="how-to-contribute"></span>

## B. 如何作出贡献

1.  填写如下表格。

2.  单击 **生成 YAML** 生成片段。

3.  单击 **在 GitHub 上打开 PR** 在 GitHub 的网页编辑器中打开文件( YAML 自动复制到剪贴板中)。

4.  粘贴生成的 YAML 尾端 `adopters:` 在文件中列出。

5.  提交更改并打开拉动请求 。

> **说明**
>
> 所有向ROS 2文件存储库提出的拉动请求都要求 [开发者原产地证书( DCO)](https://developercertificate.org/) 。如果您使用 GitHub 网页编辑器,则 [DCO 机器人](https://github.com/apps/dco) 将会对您的 PR 进行批注, 并指示如果挂号缺失, 将添加该签注。 要通过命令行签名, 请使用 `git commit --signoff`.

# 统计指标

我们不追踪 ROS 用户，但会衡量 ROS 社区的多个方面，以了解和跟踪工作产生的影响，并找出需要改进之处。

<span id="live-project-metrics"></span>

## 实时项目指标

- [metrics.ros.org](https://metrics.ros.org) 提供更新较及时的 ROS 社区指标可视化。
- [Linux Foundation 的 ROS LFX 仪表板](https://insights.linuxfoundation.org/project/ros?)提供最新的贡献者、开发、受欢迎程度和项目健康状况指标。
- [OSU OSL AWStats 仪表板](https://awstats.osuosl.org/reports/packages.ros.org/2026/01/awstats.packages.ros.org.html)提供 ROS 软件包下载的实时数据。

*注意：要获取最新信息，需要在 AWStats 网址中指定当前的年份和月份。*

- GitHub 维护了带有 [#ROS](https://github.com/topics/ros) 和 [#ROS2](https://github.com/topics/ros2) 标签的软件包和项目列表。
- Google Scholar 提供原始 [ROS 论文的最新引用列表](https://scholar.google.com/scholar?cites=1227661396257612398&as_sdt=2005&sciodt=0,5&hl=en)（[Quigley 等，2009](http://lars.mec.ua.pt/public/LAR%20Projects/BinPicking/2016_RodrigoSalgueiro/LIB/ROS/icraoss09-ROS.pdf)），以及标准 [ROS 2 论文的最新引用列表](https://scholar.google.com/scholar?oi=bibs&hl=en&cites=1227661396257612398&as_sdt=5)（[Macenski 等，2022](https://www.science.org/doi/abs/10.1126/scirobotics.abm6074)）。

<span id="periodic-metrics-report"></span>

## 定期统计报告

我们定期发布统计报告，从量化角度呈现 ROS 社区的情况。我们共同探索应当衡量哪些内容、如何衡量，并随着系统变化不断改进。欢迎反馈！有关改进报告的建议，请发布到 [Open Robotics Discourse 的网站反馈分区](https://discourse.openrobotics.org/c/site-feedback/3)。

# 统计指标

虽然我们没有跟踪ROS用户,但我们确实衡量ROS社区的各个方面,以了解和跟踪我们工作的影响,并确定需要改进的领域。

<span id="live-project-metrics"></span>

## 实时工程计量

- [标准. ros.org](https://metrics.ros.org) 是一个网站,主机相对而言可以直观地显示关于ROS社区的衡量标准。

- [Linux基金会在ROS上的LFX仪表板](https://insights.linuxfoundation.org/project/ros?) 其中包括最新的贡献者、发展、受欢迎程度和项目卫生衡量标准。

- [我们的OSU OSL AWStats仪表板](https://awstats.osuosl.org/reports/packages.ros.org/2026/01/awstats.packages.ros.org.html) 提供ROS包下载的实时数据.

*请注意, 您需要在 AWstats URL 中指定当前月份和年份以获取最新信息 。*

- Github 主控一个完整的软件包和项目列表 [\#罗斯#](https://github.com/topics/ros) 财务报告和财务报告 [{\fn方正粗倩简体\fs12\an8\1cHFFFF00\b0}二号](https://github.com/topics/ros2).

- 原件的最新引文列表 [ROS 纸张](https://scholar.google.com/scholar?cites=1227661396257612398&as_sdt=2005&sciodt=0,5&hl=en) ([Quigley等人,2009年。](http://lars.mec.ua.pt/public/LAR%20Projects/BinPicking/2016_RodrigoSalgueiro/LIB/ROS/icraoss09-ROS.pdf)),和峡谷(英语: [ROS 2 纸](https://scholar.google.com/scholar?oi=bibs&hl=en&cites=1227661396257612398&as_sdt=5) ([Macenski等人,2022年](https://www.science.org/doi/abs/10.1126/scirobotics.abm6074))在Google Scholar上都可以访问.

## 定期计量报告

我们定期发表一份衡量标准报告,以提供俄罗斯统计局社区的量化观点。我们正在集体学习如何衡量、如何以及随着系统变化而演变。请提供反馈。 请添加你关于如何改进这些报告的建议,将报告张贴到 [开放机器人演讲站点反馈分类](https://discourse.openrobotics.org/c/site-feedback/3).

# 话题

主题是ROS 2. 提供接口的三种主要风格之一. 主题应用于连续数据流,如传感器数据,机器人状态等.

如前所述,ROS 2是一个很强型的匿名出版/订阅系统。 让我们把这句话拆散一下,再多解释一点。

<span id="publish-subscribe"></span>

## Publish/Subscribe

出版/订户系统是数据生产者(出版商)和数据消费者(订户)的系统。出版商和订户知道如何通过“专题”的概念互相联系,“专题”的概念是一个共同的名称,使各实体能够找到对方。例如,当你创建一个出版商时,你还必须给它一个作为主题名称的字符串;订阅者也是如此。任何出版商和同名的订户都可以直接相互联系。任何特定专题的出版商和订户可能都是零或更多。当任何出版商发布数据时,系统的所有订户都会收到数据。这个系统也被称为“总线”,因为它与电气工程的设备总线有些相似。 总线的概念是使ROS 2成为一个强大和灵活的系统的一部分。出版商和订阅者可以根据需要来来去,这意味着调试和反省是系统的自然延伸。例如,如果你想记录数据,可以使用此系统。 `ros2 bag record` 在引擎盖下 `ros2 bag record` 在不中断数据流向系统其他部分的情况下,创建一个新用户来访问您所讲的任何主题。

<span id="anonymous"></span>

## 匿名组织

引言中提到的另一个事实是ROS 2是“匿名的 ” 。 这意味着当一个订阅者得到一块数据时,它一般并不了解或关心最初发送该数据的出版商(尽管它可以找出它是否想要 ) 。 这种架构的好处在于,出版商和订阅商可以随意互换,而不影响系统的其他部分。

<span id="strongly-typed"></span>

## 强型

最后,导言还提到,出版/订阅系统是“强型的”。

1.  ROS 信件中每个字段的类型都打字,并且该类型在不同级别上执行。例如,ROS 信件中是否包含:

    ``` default
    uint32 field1
    string field2
    ```

    然后代码会确保 `field1` 总是一个无符号的整数,而且 `field2` 总是弦。

2.  每个字段的语义定义明确。 没有自动机制来保证这一点, 但所有 ROS 核心类型都有很强的语义关系。 例如, IMU 消息包含一个测量角速度的三维向量, 每个维度被指定为弧度/ 秒。 其他解释不应该放在消息中 。

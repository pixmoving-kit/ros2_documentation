# 启动

ROS 2 系统通常包含许多节点，它们运行在不同的进程中，甚至分布在不同计算机上。
虽然可以手动启动每个节点，但节点增多后，这种方式会很繁琐。

ROS 2 的启动系统可以用一条命令自动运行多个节点。
用户通过它描述系统配置，启动系统再按配置执行。
配置内容包括运行哪些程序、在哪里运行、传递哪些参数，以及 ROS 特有的约定。这些约定使组件能够通过不同配置在整个系统中复用。
启动系统还负责监控已启动进程的状态，并在状态变化时报告情况或采取相应措施。

上述配置都写在“启动文件”中。启动文件可以使用 XML、YAML 或 Python 编写。
通过 `ros2 launch` 命令运行该文件，即可启动其中指定的所有节点。

要学习如何编写和使用启动文件，请参阅[启动教程](../../Tutorials/Intermediate/Launch/Launch-Main.md)。

更详细的信息见 [launch 文档](https://docs.ros.org/en/rolling/p/launch)。

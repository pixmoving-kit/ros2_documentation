# 关于 ROS

ROS（Robot Operating System，机器人操作系统）是一个开源生态系统，为机器人应用的构建、部署、运行和维护提供框架、工具与库。本文介绍这一生态系统的主要组成部分及其用途。

**领域：ROS 框架、ROS 工具、ROS 功能｜内容类型：介绍｜经验要求：入门**

<span id="summary"></span>

## 小结

ROS 广泛应用于机器人领域。在物流场景中，它通过导航、建图、运动控制和多机器人协调，帮助机器人在仓库中搬运货物。在制造业中，它支持自动抓取和放置等高级任务，并借助视觉系统实现精确操作。在医疗领域，ROS 支持协助患者护理的机器人系统，提高临床工作流程的效率。

观看 [ROS 介绍视频](https://vimeo.com/237016358) ，快速了解 ROS。

<span id="the-ecosystem"></span>

## 生态系统

尽管名为“操作系统”，ROS 实际上并非传统意义上的操作系统，而是一组工具和库，帮助开发者使用不同平台和编程语言构建机器人。

![ROS 生态系统概览动画](images/ROS-ecosystem.gif) <span id="framework"></span>

## 框架

ROS 框架是机器人通信的基础设施，既支持机器人不同部件之间的通信，也支持部件内部的通信。它包含消息传递、标准接口，并支持多种编程语言和平台。

例如，框架负责将摄像头数据发送到处理节点，或将规划系统的指令传递给电机控制器。它还为跨系统共享软件提供结构，使开发者能够构建模块化、可复用的解决方案。

ROS 包含以下基本组成部分：

- 节点

- 接口（话题、服务和动作）

- 参数

- 客户端库

<span id="tools"></span>

## 工具

ROS 工具帮助开发者构建、测试和监控机器人系统。它们不直接增加机器人的行为能力，而是让开发工作更加便捷。

例如，可视化工具可在测试期间以三维方式显示机器人的传感器、位置和环境，这在无人机或移动机器人项目中很常见。启动控制工具让开发者能够在实际部署前定义并验证机器人的启动方式及运行管理方式。数据录制与回放工具可以记录机器人行为，供后续检查，在排查机器人行为异常时尤为有用。

ROS 提供的核心工具涵盖以下开发工作：

- 内省

- 分析

- 节点管理

- 调试

- 构建

- 可视化

- 软件包文档

<span id="capabilities"></span>

## 功能

ROS 中的功能包提供可直接使用的机器人通用能力，例如机械臂操作、运动规划和感知。开发者可以借助这些软件包添加高级行为，而不必从零开始实现。

例如，操作类软件包可以控制机械臂，在自动化流程中抓取和放置物体。运动规划软件包通过计算环境中的安全路径，让机器人从一个位置移动到另一个位置。感知软件包帮助机器人检测和识别物体或人员，支持取物等任务，以及需要机器人根据观察结果作出响应的场景。同一种功能可以有不同实现，开发者可以切换实现并通过实验选择最符合需求的方案。

>
> 除 Open Robotics 维护的软件包之外，你还可以选择 ROS 社区贡献的众多软件包。

ROS 通过内置功能或受支持的第三方方案，提供以下核心能力：

- 仿真

- 运动规划

- 导航

- 操作

- 感知

<span id="community"></span>

## 社区

ROS 社区由全球开发者、研究人员、企业和贡献者组成，共同推动开源软件库的发展和改进。大家可以贡献通信基础设施、工具和功能包。借助社区，分享代码、交流想法和协作开发项目更加方便。

<span id="integrations"></span>

## 集成

ROS 与 Open Robotics 的其他平台协作，简化开发和部署。

- [Gazebo](https://gazebosim.org/home)：提供基于物理的仿真，让开发者在使用真实硬件之前先在虚拟环境中测试机器人。

- [开放的RMF](https://www.open-rmf.org/) （机器人中间件框架）：帮助不同机器人协同工作，并与电梯、门等楼宇系统交互。

- [旋转控制](https://control.ros.org/rolling/index.html)：支持使用 ROS 实现机器人实时控制。

这些集成简化了复杂环境中机器人的设计、测试和管理，适用于不同预算和团队规模。

<span id="ros-distributions"></span>

## ROS 发行版

ROS 发行版是按照固定周期发布的一组 ROS 软件。每个发行版提供稳定版本的核心库和工具，以及许多社区软件包，方便开发者使用一致的代码基础并保持项目兼容性。

ROS 有两个主要版本：

- [ROS 1](https://index.ros.org/)：最初的框架。

- ROS 2：当前仍在积极开发的版本。

ROS 1 已结束开发，不再计划发布新版本；ROS 2 则持续开发，并每年发布新的发行版。这些发行版包含更新与改进，开发者可以在稳定性与最新功能之间作出选择。

<span id="supported-systems"></span>

## 支持的系统

ROS 可运行于 Ubuntu、Windows 和 macOS，但我们强烈建议使用所选 ROS 发行版的 Tier 1 平台。macOS 上的 ROS 由社区提供支持，不建议初学者使用。

Ubuntu 的支持情况取决于 ROS 发行版，每个发行版要求特定的 Ubuntu LTS（长期支持）版本。在其他平台上，可能需要从源码构建或使用容器。

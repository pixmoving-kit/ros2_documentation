# 关于 ROS

ROS（Robot Operating System，机器人操作系统）是一个开源生态系统，为机器人应用的构建、部署、运行和维护提供框架、工具及库。本文介绍这个生态系统的主要组成部分及其用途。

**领域：ROS 框架、ROS 工具、ROS 功能 | 内容类型：介绍 | 经验水平：初学者**

<span id="summary"></span>

## 概述

ROS 应用于机器人领域的许多场景。在物流领域，它通过导航、建图、运动控制和多机器人协调，帮助机器人在仓库中搬运货物。在制造业，它支持自动抓取和放置等高级任务，并利用视觉系统实现精确操作。在医疗领域，ROS 为辅助患者护理、提高临床工作流程效率的机器人系统提供支持。

观看 [ROS 视频](https://vimeo.com/237016358)，快速了解 ROS。

<span id="the-ecosystem"></span>

## 生态系统

虽然名字中带有“操作系统”，但 ROS 实际上并不是传统意义上的操作系统，而是一组工具和库，帮助开发者使用不同平台和编程语言开发机器人。

![ROS 生态系统的高层概览动画](images/ROS-ecosystem.gif)

<span id="framework"></span>

## 框架

ROS 框架是机器人各个部分之间以及各部分内部进行通信的基础设施。它提供消息传递、标准接口，以及对多种编程语言和平台的支持。

例如，框架负责将相机数据发送给处理节点，或将规划系统的命令传递给电机控制器。它也为跨系统共享软件提供结构，使开发者能够构建模块化、可复用的解决方案。

ROS 包括以下基本组件：

- 节点
- 接口（话题、服务和动作）
- 参数
- 客户端库

<span id="tools"></span>

## 工具

ROS 工具帮助开发者构建、测试和监控机器人系统。这些工具本身不会为机器人增加新的行为，但可以简化开发工作。

例如，可视化工具可以在测试过程中，以三维方式显示机器人的传感器、位置和环境，这在无人机或移动机器人项目中很常见。借助启动控制工具，开发者可以在实际部署之前，定义并验证机器人的启动方式和运行管理方式。数据记录与回放工具可以记录机器人行为，供后续检查，尤其适合排查机器人行为出错的原因。

ROS 提供的核心工具涵盖开发流程中的以下环节：

- 内省（查看系统内部状态）
- 分析
- 节点管理
- 调试
- 构建
- 可视化
- 软件包文档

<span id="capabilities"></span>

## 功能

ROS 功能由可直接使用的软件包提供，涵盖操作、运动规划和感知等机器人常用功能。开发者可以借助这些软件包添加高级行为，而不必从头实现。

例如，操作软件包可以控制机械臂，在自动化流程中完成物体抓取和放置。运动规划软件包通过计算环境中的安全路径，使机器人能够从一处移动到另一处。感知软件包使机器人能够检测和识别物体或人员，支持取物等任务，以及需要根据所见情况作出响应的工作场景。同一功能的不同实现让开发者能够切换并试验，找到最符合需求的实现。

!!! note "说明"

    除了 Open Robotics 维护的软件包，还可以选择 ROS 社区贡献的许多软件包。

ROS 通过自带软件或受支持的第三方方案，提供以下核心功能：

- 仿真
- 运动规划
- 导航
- 操作
- 感知

<span id="community"></span>

## 社区

ROS 社区是由全球开发者、研究人员、公司和贡献者组成的网络，共同推动开源软件库的发展与完善。大家可以为基础设施、工具和功能作出贡献。社区也让代码共享、想法交流和项目协作变得更加方便。

<span id="integrations"></span>

## 集成

ROS 与其他 Open Robotics 平台配合，使开发和部署更加便捷。

- [Gazebo](https://gazebosim.org/home)：提供基于物理的仿真，让开发者能够在使用真实硬件之前，先在虚拟环境中测试机器人。
- [Open-RMF](https://www.open-rmf.org/)（Robotics Middleware Framework，机器人中间件框架）：帮助不同机器人协同工作，并与电梯、门等楼宇系统交互。
- [ros-controls](https://control.ros.org/rolling/index.html)：支持使用 ROS 对机器人进行实时控制。

无论预算多少、团队规模大小，这些集成都能简化复杂环境中机器人的设计、测试和管理。

<span id="ros-distributions"></span>

## ROS 发行版

ROS 发行版是按固定计划发布的一组 ROS 软件。每个发行版都包含稳定版本的核心库和工具，以及许多社区软件包，使开发者更容易基于一致的代码库工作，并保持项目兼容性。

ROS 有两个主要版本：

- [ROS 1](https://index.ros.org/)：最初的框架。
- ROS 2：当前仍在积极开发的版本。

ROS 1 的开发已经结束，不再计划发布新版本；ROS 2 则继续开发，并且每年发布新的发行版。这些发行版包含更新和改进，让开发者能够在稳定性与最新功能之间作出选择。

<span id="supported-systems"></span>

## 支持的系统

ROS 可以运行在 Ubuntu、Windows 和 macOS 上，但强烈建议使用所选 ROS 发行版的 Tier 1 平台。macOS 上的 ROS 由社区提供支持，不建议新用户使用。

Ubuntu 支持情况取决于 ROS 发行版，每个发行版都要求特定的 Ubuntu LTS（长期支持）版本。其他平台可能需要从源码构建，或通过容器运行。

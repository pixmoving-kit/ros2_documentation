# ROS 2 中文文档

**机器人操作系统(ROS)是一套用于构建机器人应用的软件库和工具.** 从驱动器和最先进的算法到强大的开发者工具,ROS拥有你下一个机器人项目所需的开源工具.

[学习更多关于ROS的知识](About-ROS.md#aboutros)

自2007年启动ROS以来,机器人和ROS社区发生了很大变化。 ROS 2项目的目标是适应这些变化,利用ROS 1的伟大之处,改善那些没有改变的东西。

**您是否正在寻找像 MoveIt, image\_ proc, 或 octomap 这样的 ROS 软件包的文档 ?** 请看 [ROS 指数](https://index.ros.org/?search_packages=true#rolling) 或检查出 [按包装文件的这一索引](https://docs.ros.org/en/rolling/p/).

本站点包含ROS 2. 的文档. 如果您需要ROS 1 的文档,请查看 [ROS 维基](https://wiki.ros.org).

如果你在工作中使用ROS 2,请看 [引用](Citations.md) 援引《规则》第2条。

## ROS社区资源

如果你需要帮助,有想法,或者想为项目捐款,请访问我们的ROS社区资源.

- [官方 ROS Zulip 讨论和支持频道](https://openrobotics.zulipchat.com/) (ROS 1、ROS 2)

- [机器人堆栈交换 - 社区QQA网站](https://robotics.stackexchange.com/) (ROS 1、ROS 2)

  - 见 [联系人页面](Contact.md#using-robotics-stack-exchange) 欲了解更多情况

- [打开机器人演讲](https://discourse.openrobotics.org/) (ROS 1、ROS 2)

  - 为ROS社区举办一般性讨论和公告论坛

  - 见 [联系人页面](Contact.md#using-ros-discourse) 欲了解更多情况

- [ROS 指数](https://index.ros.org/) (ROS 1、ROS 2)

  - 所有软件包的索引列表(即: [Python 软件包索引( PyPI)](https://pypi.org/) 用于ROS软件包)

  - 查看支持软件包的 ROS 分布

  - 链接到软件包的仓库、 API 文档或网站

  - 检查软件包的许可证、构建类型、维护者、状态和依赖性

  - 为软件包获取更多信息 [机器人堆栈交换](https://robotics.stackexchange.com/)

- [ROS 资源状态页面](https://status.openrobotics.org/) (ROS 1、ROS 2)

  - 请检查discourse或ROS建农场等ROS资源的现状.

- [ROS 基础设施项目页](https://infrastructure.openrobotics.org/) (ROS 1、ROS 2)

  - ROS基础设施项目维护 [ROS 建设农场](https://build.ros2.org/) 用于构建二进制软件包 [ROS 指数](https://index.ros.org/).

  - ROS基础设施项目还开发和维护了通常与ROS有关的工具,例如: [布鲁姆](https://bloom.readthedocs.io/) 财务报告和财务报告 [科尔康](https://colcon.readthedocs.io/en/released/).
